About RealWorth

Educational research. Not financial advice.

Research you can inspect.

RealWorth — Bitcoin, Gold & Purchasing Power Research — is an independent, public educational project comparing the purchasing power and risks of Bitcoin, gold, US equities and Treasury funds. It uses plain HTML and JavaScript, derived financial data and transparent analysis rules.

Who maintains this project?

The project is maintained through the public Ethanli0831/RealWorth GitHub repository. Code contributions and changes are visible in its commit history. No professional investment licence, institutional endorsement or peer-review status is claimed.

What the tools can establish

Historical returns, drawdowns and inflation-group distributions describe observed data. A money-purpose questionnaire screens a limited set of assets using disclosed rules and self-reported needs. Forecasts are frozen and later checked against observations. None of these proves future profitability or a best entry price.

Sources, limitations and corrections

Methodology lists the formulas, source tickers, missing-data handling and screening assumptions. Data dates are shown alongside each tool. The independent exact-return implementation does not claim to reproduce the original paper's numerical results within its original tolerance.

News templates are distinct from actual model-generated interpretations. Both can be wrong. World Gold Council physical-demand series, comparable option skew and local Canadian purchasing-power calculations are not automatically connected. Current GLD full-fund holdings can be unavailable when its source does not supply a comparable dataset.

To report a reproducible error, use GitHub Issues, including the page, observation date and expected versus actual behaviour. Do not include account credentials or private financial details.
