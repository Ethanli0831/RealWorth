一、计算一笔钱实际保留了多少购买力

选择买入月份、持有期限和金额，同时比较五种资产的实际价值、期间最大回撤，以及经历损失后首次恢复买入购买力的时间。月度数据无法反映每一次日内下跌，缺失 CPI 不会被填造。

打开实际回报计算器 →

二、研究不同起点和通胀环境

默认使用所有资产共同拥有的历史区间，也可切换完整历史。查看持有一年、三年、五年时的历史窗口分布，以及高低通胀、通胀上升与下降时的收益样本量、均值和中位数。历史比例不是未来成功率。

打开购买力与风险研究 →

三、监测市场，并检验预测后来怎样了

阅读相关新闻、宏观信号、基金与衍生品数据，以及有冻结记录的次日价格情景。比较预测误差与价格不变基准，并查看发布之后的真实结果。次日模型没有证明可靠赚快钱的方法，不代表长期投资一律不适合。

建议如何生成？

资金用途问答区分必要资金、储蓄、闲钱和借款，并考虑期限、损失承受能力、应急金、债务和花钱货币。结果可以是先保护资金、进一步研究、降低单项投入后再比较，或补充汇率评估。每项解释保留数据日期与依据；筛选假设和实测数据分开说明，不保证本金或收益。

来源与更新

长期回报研究使用 Yahoo Finance 的派生指数与 FRED 美国 CPI（CPIAUCSL）。市场监测另使用标注来源的公共信息。研究按月请求更新，新闻和报价约每十五分钟请求更新；来源发布与 GitHub 队列会造成延迟。缺失和过期数据会保留明确提示。

代码采用 MIT 许可证。第三方数据与模型保留各自条款。本站不是完整个人财务规划，也未完成加元或其他非美元的本地购买力评估。
